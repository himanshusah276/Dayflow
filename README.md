# Dayflow – Human Resource Management System

> *Every workday, perfectly aligned.*

Dayflow is a **Human Resource Management System (HRMS)** that simplifies everyday HR operations through role-based access, employee management, attendance tracking, leave approvals, and payroll visibility. It is designed for both **Employees** and **Admin/HR Officers** to manage workplace tasks efficiently. <FileCite ref_id="turn0file0" line_range_start=5 line_range_end=17 />

## ✨ Features

- Secure Sign Up & Sign In with role-based access
- Employee profile management
- Daily & weekly attendance tracking with check-in/check-out
- Leave request and approval workflow
- Payroll visibility for employees
- Admin dashboard for employee, attendance, and payroll management <FileCite ref_id="turn0file0" line_range_start=33 line_range_end=111 />

## 👥 User Roles

| Role | Access |
|------|--------|
| **Employee** | Profile, attendance, leave requests, payroll |
| **Admin/HR** | Employee management, attendance, leave approvals, payroll |

## 🔄 Workflow

```text
Employee → Login → Dashboard → Attendance / Leave / Profile

Admin → Login → Dashboard → Manage Employees → Approve Leave → Payroll
```
